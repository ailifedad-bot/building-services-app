# خدمات فنی ساختمان

نسخه آزمایشی فارسی و سازگار با موبایل برای ثبت و پیگیری درخواست خدمات ساختمانی.

## امکانات
- برق ساختمان، لوله‌کشی و تأسیسات، فاضلاب و تخلیه
- فرم ثبت درخواست با منوهای کشویی
- اطلاعات تماس، شهر، نشانی و توضیحات
- فهرست درخواست‌ها، فیلتر وضعیت و نمایش جزئیات
- تاریخچه تغییر وضعیت
- نقش‌های آزمایشی کاربر، فنی‌کار و مدیر
- پذیرش درخواست و ثبت پایان کار توسط فنی‌کار
- ذخیره‌سازی محلی در مرورگر (LocalStorage)

## اجرا
فایل `index.html` را در Chrome باز کنید یا GitHub Pages را برای مخزن فعال کنید.

## محدودیت‌ها
این نسخه نمونه اولیه سمت کاربر است. اطلاعات فقط در همان مرورگر ذخیره می‌شود. احراز هویت واقعی، پایگاه داده، همگام‌سازی، پیامک/اعلان، پرداخت و کنترل دسترسی امن هنوز وجود ندارد. نقش‌ها فقط برای آزمایش هستند.
